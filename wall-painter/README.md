# 🖌️ Wall Painter

RisuAI 채팅 장면에 맞춰 채팅 배경을 자동으로 바꾸는 플러그인입니다. (RisuAI 플러그인 API v3)

- **설치 파일:** [wall_painter.js](https://raw.githubusercontent.com/ballpotato/risu-plugins/main/wall-painter/wall_painter.js)
- **라이선스:** [CC BY-NC-SA 4.0](LICENSE)

## 주요 기능

- **장면 감지:** 봇 자체 배경 출력(상태창·이미지·채팅 변수) → 메인모델 `[BG:]` 태그 → 보조모델 판단
- **봇·모듈 에셋 스캔:** 파일명으로 배경을 골라 장소·시간대·계절 태그 부여
- **배경 라이브러리:** 캐릭터 전용 · 전체 공통, 직접 추가, 검토, 이미지별 ON/OFF
- **배경 모드:** 단일 배경 · 실시간(기준선 / 화면 점유율)
- **효과:** 흐림 · 어둡게 · 비네팅 · 그레인 · 시간대 색감 · 크로스페이드 · 스와이프
- **프리셋:** JSON(참조) · ZIP(이미지 포함) 공유, 프롬프트 편집과 .md 내보내기

## 사용 방법

1. 설정 → 플러그인에서 `wall_painter.js` 추가
2. 권한 허용 (메인 화면 · 요청 수정 · DB 읽기)
3. 채팅 화면의 붓 버튼 → 배경 에셋이 있는 봇은 **에셋 스캔하기**, 없으면 **이미지 추가**
4. 배경 카드를 펼쳐 장소 · 시간대 · 계절 · 태그 설정
5. 채팅하면 답변마다 배경이 자동으로 바뀝니다

## 참고

- 원작자 출력과 메시지 원문은 수정하지 않습니다.
- 보조모델 판단은 태그 없는 답변마다 보조모델을 호출합니다. (설정에서 끌 수 있음)
- 주로 PC · PocketRisu 환경에서 테스트되었습니다.
